# API source reference

[API contracts](api/Api.kt) match API 1.1.0 in MetroFuse KMP. These files describe the host contract. Production plugin implementations and packages belong in their own repositories.

Use [MetroFuse-JioSaavn](https://github.com/956tris/MetroFuse-JioSaavn) as the complete JavaScript and native reference plugin. The [native guide](../docs/native-plugin-development.md) explains how to compile a separate plugin against an exported host API JAR.
